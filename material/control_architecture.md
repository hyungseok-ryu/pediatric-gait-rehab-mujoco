# 소아 보행재활 로봇 제어 아키텍처 요약

현재 실시간 UI의 재활 운동은 `Automatic`, `Active`, `Sit-to-Stand` 세 모드로 구성합니다. 외골격형 로봇은 관절각을 직접 추종하고, 말단 구동형 로봇은 같은 하지 운동으로부터 계산한 발목 궤적을 추종합니다. 아래 모드 정의에서 임상 논문이 구체적으로 밝히지 않은 값은 **시뮬레이션 검증용 가정**으로 구분했습니다.

---

## 1. Automatic mode

Automatic은 외골격이 건강한 소아 보행 데이터에서 만든 기준 관절 궤적을 주도적으로 반복 재생하는 완전 보조 모드입니다.

* 기준 입력은 오른쪽 보행 한 주기의 `hip/knee` 각도이며, 왼쪽은 50% 위상 이동한 대칭 교대보행으로 생성합니다.
* UI의 보행 속도는 기준 궤적의 진행률을 조절하며, 환자의 현재 움직임이나 힘 입력은 진행 여부에 사용하지 않습니다.
* 기립 대기 또는 안전 정지에서 진입할 때는 현재 관절 자세에서 기준 보행 자세까지 S-curve로 연결하여 목표각과 목표속도의 급격한 변화를 줄입니다.
* 현재 모델에는 능동 발목 자유도가 없으므로 `hip/knee` 기준 궤적을 사용하고, 발목 위치는 하지 순기구학으로 계산합니다.

## 2. Active mode

Active는 Automatic과 동일한 기준 보행 궤적을 사용하지만, 환자의 자발적 힘을 **궤적 진행의 조건**으로 사용합니다.

* 오른쪽 보행 주기 기준 오른쪽 swing은 `60~100%`, 50% 앞선 왼쪽 swing은 `10~50%`로 가정합니다.
* 매 swing 진입 시 진행 gate를 잠급니다. 가상 환자 힘 입력이 UI의 진행 기준보다 작으면 gait cursor를 현재 값에 고정하며, 목표 관절각도 현재 보행 자세에 그대로 유지되므로 기립자세로 되돌아가지 않습니다.
* 힘 입력이 한 번 기준 이상이 되면 해당 swing이 끝날 때까지 진행 허가를 유지하고, 정지했던 위치부터 같은 기준 궤적을 계속 실행합니다. 다음 swing에서는 gate를 다시 잠그며, stance 구간은 힘 기준과 무관하게 진행합니다.
* 이 구현은 보조 토크를 `100%→70%→40%`처럼 연속 변경하는 assist-as-needed가 아닙니다. 현재 보조율 설정은 별도의 관절별 토크 배율이고, Active의 핵심은 effort-gated trajectory progression입니다.
* 환자 힘 입력은 실제 센서가 없는 현재 시뮬레이션의 수동 시험값입니다. 실제 장치에서는 힘·토크 센서의 종류, 필터, 지속시간, 히스테리시스와 오검출 안전조건을 별도로 설계해야 합니다.

## 3. Sit-to-Stand mode

Sit-to-Stand는 보행 주기와 독립된 1회성 양측 hip/knee 전환 운동입니다. 버튼을 다시 누르면 한 회를 다시 시작합니다.

1. 현재 자세에서 앉은 기준 자세까지 `부드러운 시작 시간` 동안 이동합니다.
2. 앉은 자세를 1초 유지합니다.
3. UI에서 정한 `앉기-서기 상승 시간` 동안 중립 기립자세로 이동합니다.
4. 완료 후 기립자세를 유지합니다.

시뮬레이션의 앉은 기준 자세는 임상 논문에 궤적이 제시되지 않았기 때문에 고관절 굴곡 `45°`, 무릎 굴곡 `75°`로 가정했습니다. 좌우 환자별 ROM이 이보다 좁으면 각 관절 목표를 해당 범위 안으로 제한합니다. 각 구간은 시작과 끝에서 속도와 가속도가 0인 5차 시간 스케일링을 사용합니다.

> 현재 모델은 골반이 공간에 고정되어 있고 발-지면 접촉과 체중이동을 모델링하지 않습니다. 따라서 이 모드는 실제 의자에서 체중을 지지하며 일어나는 생체역학 검증이 아니라, 공중에서 양측 hip/knee와 로봇이 전환 궤적을 추종하는 제어 시연입니다.

## 4. 공통 저수준 제어

* 사람 다리는 MuJoCo position actuator로 기준각을 재생합니다.
* 외골격형은 같은 hip/knee 목표각을 PD 제어로 추종합니다.
* 말단 구동형은 hip/knee 목표에서 발목 위치를 계산하고, 2-link IK로 변환한 모터 목표각을 PD 제어로 추종합니다.
* 안전 정지에서는 로봇 명령 토크를 0으로 만들며, 해제 후에는 현재 실제 관절각부터 다시 완만하게 연결합니다.
* 관절별 보조율, ROM hard limit와 60 mm 발목 추종 오차 안전 정지는 세 모드에 공통으로 적용합니다.

## 5. `ik_pd` 모드 (역기구학 + PD 제어)
로봇팔 모터가 **능동적으로 목표 위치를 쫓아가도록 제어**하는 일반적인 로봇 제어 방식입니다.

* **동작 원리:** 사전에 계산된 사람 발목의 위치(Target)에 닿기 위해 로봇팔 관절이 꺾여야 하는 '목표 각도'를 역산(IK)한 후, 모터가 스프링처럼 그 각도를 따라가게 만듭니다(PD 제어).
* **코드 구현:**
  * **`compute_target_ee()`**: 커프(브라켓)의 길이와 장착 각도를 고려하여, 브라켓 끝단이 사람 발목에 정확히 닿을 수 있는 로봇팔 끝단의 목표 3D 좌표를 수학적으로 역산합니다.
  * **`robot_arm_ik()`**: 목표 좌표에 도달하기 위한 3개의 관절 각도(`passive`, `motor1`, `motor2`)를 기하학적으로 완벽하게 계산해냅니다.
  * **`simulate.py` (PD 제어)**: 계산된 목표 각도와 현재 로봇팔의 각도 차이(오차)를 바탕으로 `Kp`(비례)와 `Kd`(미분) 게인을 곱해 실제 모터의 구동 토크를 발생시킵니다.
* **특징:** 위치 제어를 기반으로 동작하므로, 동적으로 변하는 타겟을 쫓아갈 때 관성과 무거운 질량 때문에 물리적으로 1~2cm 수준의 **위상 지연(Tracking Lag)**이 필연적으로 발생합니다.

## 6. `constraint_id` 모드 (물리적 구속 + 역동역학)
로봇팔을 사람 발목에 **물리적으로 완벽하게 용접(Weld)시킨 뒤 끌고 다니며** 이상적인 힘을 역산하는 분석용 방식입니다.

* **동작 원리:** 물리 엔진 상에서 로봇과 사람을 완전히 묶어버립니다. 사람은 미리 정해진 보행 궤적을 강제로 걷고, 로봇팔은 그 힘에 이끌려 완벽하게 오차 없이 따라갑니다. 이때 발생하는 힘을 역동역학(ID)으로 계산합니다.
* **코드 구현:**
  * **`build_xml.py` (Constraint)**: MuJoCo 모델 XML 내부에 `<equality><weld .../></equality>` 태그를 선언하여 로봇의 브라켓 끝단과 사람 발목을 물리 엔진 단에서 완전히 하나로 묶습니다.
  * **`simulate.py`**: 로봇 모터의 자체 제어는 꺼버리고(`ctrl=0.0`), 사람 다리만 강한 게인으로 보행 궤적을 강제 추종하여 걷게 만듭니다.
  * **`mujoco.mj_inverse()`**: 구속된 상태에서 로봇팔이 사람 다리를 따라 오차 없이 끌려갈 때, 관성과 중력을 이기기 위해 로봇 관절에 "이론적으로 발생해야만 하는 완벽한 필요 토크"(`qfrc_inverse`)를 산출합니다.
* **특징:** 타겟을 **0mm** 오차로 완벽하게 추종하며, 제어기를 튜닝하거나 설계할 때 참고할 수 있는 **"가장 이상적인 정답 토크(Ground Truth)"** 프로파일을 추출하는 데 사용됩니다.

## 7. Hip/Knee 관절 구동 범위

실시간 보행재활 UI에서 오른쪽과 왼쪽의 고관절 및 무릎 관절 범위를 각각 설정할 수 있습니다. 각도 부호는 고관절 굴곡과 무릎 굴곡이 양수이고, 고관절 신전이 음수입니다.

* **현재 입력 데이터 범위:** 고관절 약 `-10.1~44.2°`, 무릎 약 `5.8~76.3°`
* **시뮬레이션 기본 범위:** 고관절 `-15~50°`, 무릎 `0~80°`
* **기립자세 조건:** 부드러운 기립·보행 전환에 사용하는 고관절 `0°`, 무릎 `5°`가 설정 범위에 포함되어야 합니다.
* **제어 적용:** 보행 목표 궤적을 먼저 설정 범위로 제한하고, 같은 값을 MuJoCo 사람 관절의 물리적 hard limit에 적용합니다.
* **로봇 구조별 적용:** 외골격형은 사람 관절과 동축 로봇 관절에 같은 범위를 적용합니다. 말단 구동형은 사람 hip/knee에 범위를 적용하고, 로봇팔 관절은 발목 궤적을 위한 IK 각도를 사용합니다.
* **기록:** 각 세션의 좌우 최소·최대 설정값은 `torque_profile.csv`에 함께 저장됩니다.

위 기본값은 현재 보행 데이터가 잘리지 않도록 정한 시뮬레이션 값입니다. 실제 CP 환자에게 적용할 범위는 환자의 수동·능동 관절가동범위, 통증, 경직과 치료 목표를 평가한 뒤 치료사가 정해야 합니다.

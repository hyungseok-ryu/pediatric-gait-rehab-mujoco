# 프로젝트 문서

| 문서 | 내용 | 상태 |
| --- | --- | --- |
| `control_architecture.md` | 현재 제어 방식과 hip/knee 관절 구동 범위 | 현재 구현 참고 |
| `end_effector_robot_arm_concept.md` | 말단 구동형 로봇의 기구학 및 설계 설명 | 구조 참고 |
| `project.md` | 프로젝트 초기에 작성된 요구사항과 설계 가정 | 초기 명세 |
| `run_batch_simulation.md` | 이전 대규모 배치 실행 조건 기록 | 과거 실험 기록 |

현재 실행 방법, 지원 로봇 구조와 기본 파라미터는 저장소 루트의 `README.md`와
`src/config.py`를 기준으로 합니다. `project.md` 및 `run_batch_simulation.md`에는
초기 또는 이전 실험의 구조명이 남아 있을 수 있습니다.

실행 결과 그림과 영상은 Git에 포함하지 않으며 로컬 `outputs/`에 생성됩니다.
